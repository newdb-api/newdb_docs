    fssp_person — Проверка ФЛ по базе ФССП¶

    POST https://api.newdb.net/v2

    Метод осуществляет поиск исполнительных производств в ФССП по ФИО, дате рождения и коду региона. Для поиска по всем регионам ФССП передайте regioncode: "100".

    Рекомендуем также: комплексная проверка по паспорту — complex_by_passport.

    Раздел: Физические лица

    Связанные страницы¶

    • Обзор раздела физические лица
    • passport_fns — Проверка паспорта/ИНН через ФНС
    • passport_mvd — Проверка паспорта РФ на действительность
    • complex_by_passport — Комплексная проверка по данным паспорта

    Когда использовать¶

    Используйте метод, когда нужно проверить физлицо, документ или связанный с ним государственный реестр по структурированным данным.

    Типовые кейсы¶

    • Проверка анкеты клиента перед onboarding или выдачей услуги
    • Автоматическая верификация паспорта, ИНН, задолженностей или ограничений
    • Обогащение внутренней карточки физлица данными из внешнего источника

    Заголовки¶

    Content-Type: application/json
X-API-KEY: <your_token>

    Входная схема (request)¶

    {
  "params": {
    "firstname": "string",
    "lastname": "string",
    "secondname": "string",
    "dob": "YYYY-MM-DD",
    "regioncode": "string | number",
    "country": "ru",
    "method": "fssp_person"
  },
  "webhook": "https://your.host/whook",
  "requestId": "optional-string"
}

    Коды регионов¶

    Параметр regioncode принимает код региона ФССП. Для кодов с ведущим нулём (01, 07, 09 и т.д.) передавайте значение строкой. Значение 100 означает поиск по всем регионам ФССП.

    Чтобы выполнить поиск по всем территориальным органам ФССП, передайте regioncode: 100. В интерфейсе ФССП это соответствует пункту «Все регионы».
