    fssp_company — Долги ФССП по связанным компаниям физлица¶

    POST https://api.newdb.net/v2

    Метод реализует сквозную проверку бизнес-рисков физического лица: 1. Принимает 12-значный ИНН физического лица. 2. В реальном времени находит все юридические лица (ООО, АО), где данное лицо выступает руководителем (генеральным директором) или учредителем/участником (по данным прозрачного бизнеса ФНС / ЕГРЮЛ). 3. По каждой действующей связанной организации запускает автоматическую проверку в официальном банке данных исполнительных производств ФССП России. 4. Агрегирует исполнительные производства, рассчитывает суммарную задолженность бизнеса и формирует аналитическую сводку по компаниям с долгами.

    Раздел: Физические лица | Юридические лица

    [!IMPORTANT] Метод позволяет мгновенно выявить токсичные бизнес-активы, висящие на физическом лице, и оценить риск привлечения к субсидиарной ответственности руководителей и бенефициаров компаний-должников.

    Связанные страницы¶

    • Обзор раздела физические лица
    • fssp_person — Исполнительные производства физического лица
    • complex_by_passport — Комплексная проверка по паспорту
    • court_arbitration — Арбитражные дела связанных компаний
    • arbitr_debt_sum — Сумма арбитражных задолженностей
    • egrul_untrusted — Недостоверные сведения ЕГРЮЛ

    Когда использовать¶

    • Скоринг топ-менеджеров и собственников: проверка кандидатов на руководящие должности в крупных компаниях и банках.
    • Оценка заемщиков и поручителей: физическое лицо без личных долгов может контролировать юрлица с многомиллионными взысканиями приставов.
    • Инвестиционный и M&A комплаенс: выявление скрытых судебных и исполнительных обязательств основателей бизнеса.

    Заголовки¶

    Content-Type: application/json
X-API-KEY: <your_token>

    Входная схема¶

    {
  "method": "fssp_company",
  "params": {
    "inn": "771234567890",
    "max_companies": 20,
    "only_active": true
  }
}

    Параметры запроса¶

    Параметр Тип Обязательный По умолчанию Описание
    method string Да — Имя метода: "fssp_company".
    inn string Да — ИНН физического лица (12 цифр). Также принимается innfiz.
    max_companies integer Нет 20 Максимальное количество проверяемых связанных компаний (от 1 до 50).
    only_active boolean Нет true Проверять только действующие компании (исключая ликвидированные).
    include_roles array Нет ["director", "founder"] Роли связи: "director" (руководитель), "founder" (учредитель).
    regioncode string/int Нет -1 Код региона для ФССП (по умолчанию -1 — все регионы РФ).

    Пример запроса (cURL)¶

    curl -X POST "https://api.newdb.net/v2" \
     -H "Content-Type: application/json" \
     -H "X-API-KEY: d31bed04-70b6-4686-98e6-ee8b26c43738" \
     -d '{
       "method": "fssp_company",
       "params": {
         "inn": "771234567890"
       }
     }'

    Описание полей ответа¶

    Поле Тип Описание
    data array Основной массив проверенных организаций (соответствует общей концепции data: []). Содержит объекты проверенных компаний с их долгами и производствами.
    person_inn string ИНН проверяемого физического лица.
    affiliated_companies_total integer Всего найдено аффилированных организаций по ЕГРЮЛ.
    affiliated_companies_checked integer Количество фактически проверенных компаний в базе ФССП.
    companies_with_debts integer Количество компаний, по которым найдены активные долги в ФССП.
    total_debt_amount number Суммарная задолженность всех подконтрольных компаний (в рублях).
    summary array Алиас на data — список проверенных компаний с разбивкой по ролям, долгам и производствам (для обратной совместимости).
    all_proceedings array Плоский список всех выявленных производств по всем компаниям.
