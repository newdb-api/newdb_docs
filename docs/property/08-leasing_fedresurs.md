# leasing_fedresurs — Договоры лизинга на Федресурсе

POST `https://api.newdb.net/v2`

Метод осуществляет поиск и извлечение юридически значимых сведений о **договорах финансовой аренды (лизинга)** из Единого федерального реестра юридически значимых сведений о фактах деятельности юридических лиц ([Федресурс](https://fedresurs.ru)).

В соответствии с законодательством РФ, публикация сведений о заключении, изменении, сублизинге и прекращении договоров лизинга на Федресурсе является обязательной.

Метод позволяет получить:
- Все заключенные, действующие и прекращенные/расторгнутые договоры лизинга;
- Реквизиты сторон: лизингодатель (лизинговая компания) и лизингополучатель (клиент);
- Подробное описание предмета лизинга (марка, модель, VIN автотранспорта, серийный номер спецтехники/оборудования);
- Номер и дату договора лизинга, сроки действия обязательств, номера сообщений Федресурса.

> [!IMPORTANT]
> Метод поддерживает гибкие критерии поиска:
> - **По ИНН организации (10 цифр)** или **ИНН физического лица / ИП (12 цифр)**: поиск всех договоров, где субъект выступает лизингополучателем или лизингодателем.
> - **По VIN транспортного средства**: проверка конкретного автомобиля на нахождение в лизинге.
> - **По номеру договора лизинга или номеру публикации**.

## Когда использовать

- **Проверка автотранспорта и спецтехники перед покупкой**: выявление скрытого лизинга (продажа лизингового авто без согласия лизингодателя влечет изъятие ТС).
- **Оценка долговой и имущественной нагрузки бизнеса**: анализ активных договоров лизинга компании показывает реальный объем используемых основных средств и обязательств.
- **Мониторинг расторжения и изъятия предметов лизинга**: фиксация фактов досрочного прекращения договоров лизинга из-за просрочек платежей.

## Входная схема

```json
{
  "method": "leasing_fedresurs",
  "params": {
    "inn": "7707083893"
  }
}
```

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `method` | string | **Да** | Имя метода: `"leasing_fedresurs"`. |
| `inn` | string | Нет* | ИНН юридического лица (10 цифр). |
| `innfiz` | string | Нет* | ИНН физического лица или индивидуального предпринимателя (12 цифр). |
| `vin` | string | Нет* | VIN транспортного средства (17 символов). |
| `propertyid` | string | Нет* | Номер или идентификатор имущества/сообщения. |
| `search` | string | Нет* | Текстовый поисковый запрос (номер договора, наименование стороны). |

*\*Необходимо передать хотя бы один параметр: `inn`, `innfiz`, `vin`, `propertyid` или `search`.*

---

## Пример запроса (cURL)

```bash
curl -X POST "https://api.newdb.net/v2" \
     -H "Content-Type: application/json" \
     -H "X-API-KEY: d31bed04-70b6-4686-98e6-ee8b26c43738" \
     -d '{
       "method": "leasing_fedresurs",
       "params": {
         "inn": "7707083893"
       }
     }'
```
