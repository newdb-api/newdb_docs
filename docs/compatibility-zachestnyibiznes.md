# Режим совместимости с форматом «ЗАПРАВИЛЬНЫЙБИЗНЕС» (ZB)

Для клиентов, использующих интеграционные модули, CRM-коннекторы или клиентские библиотеки, рассчитанные на распространенную в РФ схему данных ZB («ЗАПРАВИЛЬНЫЙБИЗНЕС»), NewDB поддерживает **встроенный режим конвертации ответов на лету**.

---

## Как включить формат «ЗАПРАВИЛЬНЫЙБИЗНЕС»

Вы можете запросить ответ в формате ZB любым удобным способом:

1. **Параметр в строке запроса (Query parameter):**
   * `format=zb` (или `_format=zb`, `format=ЗБ`)
2. **Поле в теле JSON-запроса:**
   * `"format": "zb"`
3. **HTTP-заголовок запроса:**
   * `X-Response-Format: zb`

---

## Структура ответа (Конверт ZB)

При включении параметра `format=zb` API NewDB оборачивает полезные данные в привычный конверт формата:

```json
{
  "status": "200",
  "message": "Запрос выполнен успешно",
  "body": { ... }
}
```

### Коды статусов (`status`):
* `"200"` — Запрос выполнен успешно. Полезные данные находятся в объекте `body`.
* `"201"` — Отсутствует параметр - ключ API (`api_key` / `token`).
* `"212"` — Истек лимит запросов по вашему тарифному плану (недостаточно средств).
* `"214"` — Задан неверный ID компании.
* `"215"` — Задан неверный ключ API.
* `"216"` — Введен неверный ОГРН/ИНН.

## Поддерживаемые методы и соответствие контрактам

| Метод NewDB | Метод / раздел ZB («За честный бизнес») | Возвращаемая структура `body` | Описание |
| :--- | :--- | :--- | :--- |
| `egrul` | `/card` (ЮЛ) | Объекты реквизитов ЮЛ (`ОГРН`, `ИНН`, `КПП`, `НаимЮЛПолн`, `Руководители`, `СумКап` и др.) | Полная карточка юридического лица по ЕГРЮЛ |
| `egrul_ip` | `/card` (ИП) | Объекты реквизитов ИП (`ОГРНИП`, `ИННФЛ`, `ФИО`, `ДатаОГРН`, `НаимОКВЭД` и др.) | Карточка индивидуального предпринимателя по ЕГРИП |
| `self_employed` | `/self-employed` | `{"status": true/false, "inn": "...", "message": "...", "registration_date": "..."}` | Статус плательщика налога на профессиональный доход (НПД) |
| `fssp_legal` / `fssp_person` | `/fssp-list` | `{"total": N, "docs": [ {"НомИспПроизв": "...", "СуммаДолга": ..., "ТребИспДок": ...} ]}` | Исполнительные производства ФССП (по компании или физлицу) |
| `arbitr_legal` / `pravo_search` | `/arbitr-list` / `/court-arbitration` | `{"total": N, "cases": [ {"Номер": "...", "Суд": "...", "СуммаИска": ...} ]}` | Арбитражные судебные дела и картотека арбитражных дел |
| `fns_block` / `fns_block_person` | `/bank-restrict` | `{"total": N, "items": [ {"bik": "...", "decision_number": "...", "decision_date": "..."} ]}` | Блокировки и приостановления операций по банковским счетам (ФНС) |
| `bankrot_legal` / `bankrot_person` | `/bankrupt-card` | `{"status": "...", "stage": "...", "arbitr_manager": "...", "case_number": "..."}` | Сведения о процедурах банкротства (Федресурс / ЕФРСБ) |
| `fns_mass_leaders` | `/mass-leaders` | `{"total": N, "is_mass": true/false, "companies": [...]}` | Реестр массовых руководителей ФНС |
| `fns_mass_founders` | `/mass-founders` | `{"total": N, "is_mass": true/false, "companies": [...]}` | Реестр массовых учредителей/участников ФНС |
| `intellectual_property` | `/trademarks` / `/patents` | `{"total": N, "items": [ {"reg_num": "...", "name": "...", "holder": "..."} ]}` | Товарные знаки, патенты и интеллектуальная собственность (Роспатент) |
| `complex_by_passport` / `complex_by_innfiz` | `/fl-card` | Комплексная анкета физлица: ФИО, ИНН, проверки массовости, ИП, самозанятость, банкротство | Полный скоринг физического лица в формате карточки физлица ZB |
| `complex_by_inn` | `/multiple-methods` / комплексная карточка ЮЛ | Карточка ЮЛ, обогащенная блоками `ФССП`, `Суды`, `БлокировкаСчетов`, `Банкротство` | Единая карточка юридического лица со всеми проверками |
| `fns_bo` | `/fs-fns` | Бухгалтерская отчетность (`Форма1`, `Форма2`, `Выручка`, `ЧистаяПрибыль`, `ДинамикаПоГодам`) | Финансовая и бухгалтерская отчетность организации (ФНС / ГИР БО) |
| `vin_check` | `/transport` / `/pledges` | Карточка ТС: марка, модель, VIN, розыск ГИБДД, ограничения, залог ФНП, периоды владения | Комплексная проверка транспортного средства по VIN / госномеру |
| `requests` / `history` | `/flcheck/data/list` | Список заявок: `{"total": N, "currentPage": 1, "data": [ {"id": "...", "status": "Готово", "ФИО": "...", "create_at": "..."} ]}` | Журнал и история проведенных проверок физлиц |
| `data` | `/flcheck/data/report` | Полный отчет по проверке физлица в структуре ЗБ | Получение результатов проверки по ее идентификатору (`id`) |

## Эндпоинты проверки физлиц в стиле ЗЧБ (`/flcheck/data/*`)

### 1. Создание проверки (`/flcheck/data/create`)
```bash
curl -X GET "https://api.newdb.net/flcheck/data/create?lastname=Иванов&firstname=Иван&secondname=Иванович&birthdate=1990-01-01&series_passport=4510&number_passport=123456&api_key=YOUR_KEY"
```
**Ответ:**
```json
{
  "status": "200",
  "message": "Запрос выполнен успешно",
  "idRequest": "900000001",
  "rem_request": 999999
}
```

curl -X GET "https://api.newdb.net/flcheck/data/list?page=1&api_key=YOUR_KEY"

- `/flcheck/data/sfact-message?fl_request_id=...&id=...` — существенный факт / залог
- `/flcheck/data/court-arbitration-card?fl_request_id=...&id=...` — карточка арбитражного дела

## Тестирование в Sandbox (без расхода баланса)

Конвертер и эндпоинты `/flcheck/data/*` полностью поддержаны в тестовом контуре NewDB API:
```bash
curl -X GET "https://api.newdb.net/test/v2/flcheck/data/report?fl_request_id=900000001"
```
Запрос мгновенно вернет тестовый 39-блочный отчет физлица в формате ЗБ без списания реального баланса.
