# intellectual_property — Патенты и интеллектуальная собственность (Роспатент / ФИПС)

POST `https://api.newdb.net/v2`

Метод выполняет онлайн-поиск по базам данных Федеральной службы по интеллектуальной собственности (Роспатент / ФИПС) по имени физического лица (автор, правообладатель) или наименованию юридического лица.

**Рекомендуем также:** проверка юридических лиц — [egrul](../legal/04-egrul.md), проверка ИП — [egrul_ip](11-egrul_ip.md), комплексная проверка физического лица — [complex_by_passport](04-complex_by_passport.md).

**Раздел:** [Физические лица](index.md)

## Когда использовать

- Оценка нематериальных активов и научно-технического потенциала контрагентов и партнеров
- Проверка реальной квалификации и портфолио ключевых специалистов, разработчиков и исследователей
- Due Diligence технологических стартапов и инновационных компаний перед M&A сделками или инвестициями
- Проверка прав на товарные знаки, патенты и изобретения при лицензировании

## Заголовки

```http
Content-Type: application/json
X-API-KEY: <your_token>
```

## Входная схема (request)

```json
{
  "params": {
    "method": "intellectual_property",
    "query": "Семенов Виктор Иванович",
    "limit": 10,
    "offset": 0
  },
  "requestId": "00000000-0000-4000-8000-000000000001"
}
```

## Параметры запроса

| Параметр | Тип | Обязательный | Описание / Алиасы |
|---|---|---|---|
| `method` | `string` | **Да** | Имя метода, всегда `intellectual_property`. |
| `query` | `string` | **Да** | ФИО автора/правообладателя или наименование организации (от 1 до 1000 символов). |
| `limit` | `integer` | Нет | Количество возвращаемых результатов на страницу (от 1 до 100, по умолчанию 10). |
| `offset` | `integer` | Нет | Смещение для пагинации (по умолчанию 0). |
| `datasets` | `array[string]` | Нет | Фильтр по типам баз данных Роспатента (например: изобретения, полезные модели, промышленные образцы). |
