# fssp_case — ФССП по номеру исполнительного производства

POST `https://api.newdb.net/v2`

Метод `fssp_case` ищет запись в банке данных исполнительных производств Федеральной службы судебных приставов (ФССП России) по номеру исполнительного производства.

Используйте метод, когда известен номер ИП, например `88442/25/66049-ИП`, и нужно получить карточку производства: данные должника, реквизиты исполнительного документа, предмет взыскания, сумму задолженности, отдел судебных приставов, телефон и пристава-исполнителя.

## Когда использовать

- Когда уже известен точный номер исполнительного производства (из отчетов, судов или баз данных) и требуется детальная карточка.
- Для мониторинга или точечной проверки конкретного ИП без необходимости передавать ФИО, дату рождения или регион.
- При автоматизации работы юристов, коллекторских агентств, служб безопасности и кредитных организаций.

## Параметры запроса

| Параметр | Обязательный | Тип | Описание |
| --- | --- | --- | --- |
| `method` | да | string | Всегда `fssp_case`. |
| `country` | да | string | Всегда `ru`. |
| `case_number` | да | string | Номер исполнительного производства ФССП в формате источника (например `88442/25/66049-ИП`). |
| `ip_number` | нет | string | Алиас для `case_number`, если в вашей интеграции используется наименование `ip_number`. |
| `requestId` | нет | string | UUID запроса для повторного получения результата. |
| `webhook` | нет | string | HTTPS URL для отправки callback с результатом. |

## Пример запроса

```json
{
  "params": {
    "method": "fssp_case",
    "country": "ru",
    "case_number": "88442/25/66049-ИП"
  },
  "webhook": "https://example.com/newdb-webhook",
  "requestId": "00000000-0000-4000-8000-000000000101"
}
```

## Примечания

- `case_number` передается как строка; сохраняйте символы `/` и суффикс `-ИП`, если они есть в исходном номере.
- Метод не требует ФИО, даты рождения, ИНН или кода региона.
- Технические ошибки источника, капчи или браузерного воркера возвращаются со статусом 500 и могут быть автоматически перезапущены.
