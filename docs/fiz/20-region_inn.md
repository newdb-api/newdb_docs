# region_inn — Определение региона выдачи ИНН

POST `https://api.newdb.net/v2`

Синхронный метод для мгновенного вычисления региона и субъекта РФ, в налоговом органе которого был поставлен на учёт налогоплательщик и присвоен ИНН (10 или 12 знаков). Метод сопоставляет первые две цифры ИНН со справочником субъектов Российской Федерации (включая Байконур и новые субъекты РФ).

Метод работает без обращения к сторонним ресурсам и выполняется мгновенно (задержка < 10 мс).

**Раздел:** [Физические лица](index.md)

## Когда использовать

- Автоматическое определение региона налогового учёта физического лица, ИП или организации.
- Валидация корректности структуры ИНН.
- Обогащение анкеты клиента и скоринговых профилей.
- Мгновенная проверка в связке с форматом ЗаЧестныйБизнес (`format=zb`), где поле транслируется в `РегионПолучИНН` и `КодРегиона`.

## Заголовки

```http
Content-Type: application/json
X-API-KEY: <your_token>
```

## Входная схема (POST)

```json
{
  "params": {
    "method": "region_inn",
    "inn": "771234567890"
  },
  "requestId": "00000000-0000-4000-8000-000000000020"
}
```

| Параметр в `params` | Тип | Обязательный | Описание |
|---|---|---|---|
| `method` | string | Да | `region_inn` |
| `inn` | string | Да | ИНН физического лица (12 цифр) или организации (10 цифр). |

Также поддерживается вызов через быстрый синхронный endpoint:
`GET https://api.newdb.net/v2/run?method=region_inn&inn=771234567890`

## Пример ответа (Успешное определение)

```json
{
  "state": "complete",
  "requestId": "00000000-0000-4000-8000-000000000020",
  "results": {
    "region_inn": {
      "result": {
        "status": 200,
        "data": [
          {
            "region_code": "77",
            "region_name": "г. Москва",
            "region_desc": "г. Москва"
          }
        ]
      }
    }
  }
}
```

## Поля ответа в `data[0]`

| Поле | Тип | Описание |
|---|---|---|
| `region_code` | string | Двузначный код субъекта РФ (например, `"77"`, `"78"`, `"50"`). |
| `region_name` | string | Официальное наименование субъекта РФ (например, `"г. Москва"`). |
| `region_desc` | string | Дополнительное описание / статус региона. |

## Пример ответа в формате ЗаЧестныйБизнес (`format=zb`)

При передаче параметра `format=zb` или заголовка `X-Response-Format: zb`:

```json
{
  "status": "200",
  "message": "Запрос выполнен успешно",
  "body": {
    "КодРегиона": "77",
    "РегионПолучИНН": "г. Москва"
  }
}
```

## Интеграция в комплексные методы

В методе комплексной проверки [complex_by_passport](04-complex_by_passport.md) определение региона выдачи ИНН (`region_inn`) выполняется автоматически сразу после получения ИНН из ФНС и включается в итоговый результат проверки.
