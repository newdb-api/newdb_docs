# fns_mass_founders — Реестр массовых учредителей (ФНС России)

POST `https://api.newdb.net/v2`

Метод выполняет проверку физического лица на вхождение в официальный реестр сведений о физических лицах, являющихся учредителями (участниками) нескольких юридических лиц (реестр массовых учредителей ФНС России).

## Когда использовать

- Оценка благонадежности учредителей и собственников бизнеса перед заключением сделок и партнерств
- Выявление номинальных учредителей и фирм-однодневок в рамках процедур «должной осмотрительности» (ст. 54.1 НК РФ)
- Кредитный и комплаенс-скоринг в банках, МФО, лизинговых и страховых компаниях
- Кадровые проверки кандидатов на топ-менеджерские позиции и материально ответственные должности

## Входная схема (request)

Запрос можно выполнять либо по **ИНН**, либо по **ФИО** (при указании обоих параметров поиск по ИНН имеет приоритет):

```json
{
  "params": {
    "method": "fns_mass_founders",
    "inn": "770200000139"
  },
  "requestId": "00000000-0000-4000-8000-000000000001"
}
```

Поиск по ФИО:

```json
{
  "params": {
    "method": "fns_mass_founders",
    "lastname": "Иванов",
    "firstname": "Иван",
    "secondname": "Иванович"
  },
  "requestId": "00000000-0000-4000-8000-000000000002"
}
```

## Параметры запроса

| Параметр | Тип | Обязательный | Описание / Алиасы |
|---|---|---|---|
| `method` | `string` | **Да** | Имя метода, всегда `fns_mass_founders`. |
| `inn` | `string` | **Да\*** | 12-значный ИНН физического лица. Приоритетный критерий поиска. Алиасы: `innfiz`, `inn_fl`. |
| `fio` | `string` | **Да\*** | Полное ФИО физического лица. Алиасы: `query`, `name`. |
| `lastname` | `string` | Нет | Фамилия (при раздельном указании ФИО вместе с `firstname`). |
| `firstname` | `string` | Нет | Имя. |
| `secondname` | `string` | Нет | Отчество. Алиасы: `middle_name`, `middlename`, `patronymic`. |

*\* Обязательно указание либо `inn` (рекомендуется), либо `fio` (или пары `lastname` + `firstname`). При передаче обоих параметров поиск по ИНН выполняется в приоритетном порядке.*
