# rnp — Реестр недобросовестных поставщиков (ЕИС Закупки)

POST `https://api.newdb.net/v2`

Метод осуществляет поиск сведений в официальном **Реестре недобросовестных поставщиков (РНП)** Единой информационной системы в сфере закупок ([zakupki.gov.ru](https://zakupki.gov.ru)). Поддерживается поиск как по ИНН (10 или 12 знаков), так и по текстовому запросу / наименованию поставщика (ФИО индивидуального предпринимателя или учредителя).

Метод проверяет все реестры и законы:
- **44-ФЗ** (Федеральный закон «О контрактной системе в сфере закупок товаров, работ, услуг для обеспечения государственных и муниципальных нужд»);
- **223-ФЗ** (Федеральный закон «О закупках товаров, работ, услуг отдельными видами юридических лиц»);
- **ПП РФ 615** (Постановление Правительства РФ № 615 по капитальному ремонту МКД);
- **94-ФЗ** (архивный реестр).

---

**Раздел:** [Юридические лица](index.md)

> [!IMPORTANT]
> Метод предназначен для проверки участников закупок и контрагентов: **юридических лиц (ИНН 10 знаков)** и **индивидуальных предпринимателей (ИНН 12 знаков)**, а также по наименованию компании или ФИО поставщика.
> 
> Метод выполняется:
> 1. **Отдельно** по ИНН (10 или 12 цифр) или по названию/ФИО (`method: "rnp"`).
> 2. **Автоматически** в рамках комплексной проверки компании по ИНН ([complex_by_inn](06-complex_by_inn.md)).
> 
> При бытовых проверках граждан по паспорту (`complex_by_passport`) метод не запускается, чтобы не перегружать проверку непрофильными реестрами.

## Когда использовать

- **Проверка благонадежности контрагента** перед заключением контракта, соглашения или участием в тендерах.
- **Комплаенс-скоринг**: нахождение в РНП блокирует участие поставщика в государственных и корпоративных закупках на 2 года.
- **Раздельный анализ статусов**: учет как действующих («Размещено»), так и архивных («Исключено») записей для оценки ретроспективных рисков.

Content-Type: application/json  
X-API-KEY: `<your_token>`

## Входная схема

```json
{
  "params": {
    "inn": "string, optional, ИНН юрлица (10 цифр) или физлица/ИП (12 цифр)",
    "query": "string, optional, Поисковый запрос / наименование поставщика / ФИО",
    "max_pages": "integer, optional, Максимальное число страниц пагинации (1-100, по умолчанию 20)",
    "country": "ru",
    "method": "rnp"
  },
  "webhook": "https://your.host/webhook",
  "requestId": "optional-string"
}
```

> [!NOTE]
> В запросе необходимо передать хотя бы один параметр: `inn` либо `query`. При указании `inn` результаты дополнительно строго фильтруются по точному совпадению ИНН поставщика.

## Структура полей ответа

- `found` (boolean) — признак наличия записей в РНП по заданному запросу (`true`, `false`, или `null` при неполных данных).
- `has_active_records` (boolean) — флаг наличия **действующих** записей со статусом «Размещено» (`true`, `false`, или `null`).
- `registry_status` (string):
  - `found` — записи найдены;
  - `not_found` — проверено, записей в реестре нет;
  - `incomplete` — достигнут лимит страниц пагинации без полного охвата.
- `meta`:
  - `active_count` (integer) — количество активных записей («Размещено»);
  - `excluded_count` (integer) — количество исключенных архивных записей («Исключено»);
  - `source_count` (integer) — общее количество записей по счетчику ЕИС;
  - `pages_fetched` (integer) — количество обработанных страниц пагинации;
  - `matching` (string) — тип сопоставления (`supplier_inn_exact` или `source_search`).
- `data[]`:
  - `registry_number` (string) — номер реестровой записи в РНП.
  - `law` (string) — закон/основание (`FZ44`, `FZ223`, `PPRF615`, `FZ94`).
  - `supplier_name` (string) — наименование поставщика (подрядчика, исполнителя) или ФИО ИП.
  - `inn` (string) — ИНН недобросовестного поставщика.
  - `eruz_number` (string) — номер реестровой записи в ЕРУЗ (при наличии).
  - `status` (string) — текстовый статус («Размещено», «Исключено»).
  - `status_code` (string) — нормализованный код статуса (`published`, `excluded`, `unknown`).
  - `is_active` (boolean) — признак активности записи (`true` для «Размещено», `false` для «Исключено»).
  - `included_date` (string) — дата включения в РНП (`DD.MM.YYYY`).
  - `updated_date` (string) — дата обновления сведений.
  - `excluded_date` (string) — фактическая дата исключения из реестра.
  - `planned_exclusion_date` (string) — плановая дата исключения (обычно 2 года с момента включения).
  - `url` (string) — прямая ссылка на карточку реестровой записи в ЕИС Закупки.

---

## Коды ответов

- `200` — запрос успешно выполнен.
- `400` — некорректные параметры (не указан `inn`/`query` либо некорректный формат ИНН).
- `500` — ошибка внешнего сервиса или превышение времени ожидания.
