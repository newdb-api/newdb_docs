# msp (fns_msp) — Реестр субъектов МСП и мер государственной поддержки

POST `https://api.newdb.net/v2`

Метод осуществляет поиск и проверку сведений в официальном **Едином реестре субъектов малого и среднего предпринимательства — получателей государственной поддержки** Федеральной налоговой службы (набор открытых данных ФНС `7707329152-rsmppp` по 209-ФЗ).

Метод позволяет оперативно проверить:
- Категорию субъекта МСП (микропредприятие, малое, среднее предприятие или плательщик НПД / самозанятый);
- Количество и детальный список всех предоставленных мер финансовой, гарантийной, консультационной и имущественной поддержки;
- Общий суммарный объем полученной государственной поддержки (в рублях);
- Факты нарушений условий предоставления поддержки (включая нецелевое использование средств) и наличие неустраненных нарушений.

> [!IMPORTANT]
> Метод универсален и поддерживает поиск:
> 1. По **ИНН юридического лица** (10 знаков);
> 2. По **ИНН индивидуального предпринимателя или самозанятого гражданина** (12 знаков);
> 3. По **ОГРН / ОГРНИП**;
> 4. По **ФИО** индивидуального предпринимателя или наименованию организации.

## Когда использовать

- **Скоринг и оценка надежности контрагента**: получение субсидий и мер господдержки подтверждает реальный статус действующего бизнеса.
- **Проверка соблюдения условий субсидирования**: наличие флага `has_violations: true` (нарушения порядка предоставления помощи) является критическим риск-фактором при андеррайтинге и кредитовании.
- **Анализ объемов финансирования**: суммарный объем финансовой поддержки (`total_support_amount`) и типы программ поддержки.

## Входная схема

```json
{
  "method": "msp",
  "params": {
    "inn": "7707083893"
  }
}
```

Поддерживается также вызов через `method: "fns_msp"`.

### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `method` | string | **Да** | Имя метода: `"msp"` или `"fns_msp"`. |
| `inn` | string | Нет* | ИНН организации (10 цифр) или ИП/самозанятого (12 цифр). |
| `ogrn` | string | Нет* | ОГРН (13 цифр) или ОГРНИП (15 цифр). |
| `fio` | string | Нет* | ФИО индивидуального предпринимателя или получателя поддержки. |
| `name` | string | Нет* | Полное или краткое наименование юридического лица. |
| `lastname` | string | Нет | Фамилия (при поиске по ФИО). |
| `firstname` | string | Нет | Имя (при поиске по ФИО). |
| `secondname` | string | Нет | Отчество (при наличии). |

*\*Необходимо передать хотя бы один критерий поиска: `inn`, `ogrn`, `fio` или `name`.*

curl -X POST "https://api.newdb.net/v2" \

## Описание полей ответа

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `found` | boolean | `true`, если субъект найден в реестре МСП. |
| `entity_type` | string | Тип субъекта: `"yur"` (юридическое лицо), `"ip"` (ИП), `"fl_npd"` (самозанятый). |
| `msp_category` | string | Категория: `"Микропредприятие"`, `"Малое предприятие"`, `"Среднее предприятие"`. |
| `support_count` | integer | Общее количество оказанных мер государственной поддержки. |
| `total_support_amount` | number | Суммарный объем полученного финансирования (в рублях). |
| `has_violations` | boolean | Флаг выявления нарушений условий господдержки. |
| `has_unresolved_violations` | boolean | Флаг наличия неустраненных нарушений. |
| `supports` | array | Список конкретных мер поддержки с суммами, датами и органами. |
