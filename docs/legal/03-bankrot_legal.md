# bankrot_legal — Проверка на банкротство юрлица (Федресурс)

POST `https://api.newdb.net/v2`

Метод выполняет проверку юридического лица на наличие сведений о банкротстве в ЕФРСБ. Поиск осуществляется по ИНН компании.

## Когда использовать

Используйте метод, когда нужно получить сведения о юридическом лице, его рисках, долгах, блокировках или судебной активности.

## Типовые кейсы

- Проверка контрагента перед сделкой или оплатой
- Автоматическое обогащение карточки компании по ИНН
- Выявление признаков банкротства, блокировок, исполнительных производств или арбитража

## Тексты сообщений Федресурса

!!! note "Подготовленное расширение ответа"
    Поля ниже реализованы в локальной версии spider `bankrot`. Доработка ещё не опубликована на рабочих серверах; до её развёртывания ответы могут содержать только ссылки, как в примере выше. Параметры запроса не меняются.

Кроме существующего `url`, для сообщений `bankrupt-message` (ЕФРСБ) и `sfact-message` (сведения о фактах деятельности) добавляются два поля:

| Поле | Описание |
|---|---|
| `short_text` | Выдержка из начала полного текста, до 500 символов. При обрезке заканчивается `…`. Это не ИИ-пересказ. |
| `full_text` | Полный текст блока «Текст сообщения» с сохранением абзацев, без обрезки по длине. Не включает меню сайта, блок подписи и содержимое приложенных файлов. |
| `url` | Исходная ссылка на сообщение, сохраняется без изменений. |

Новые поля находятся внутри записей:

- `result.data[].bankruptcy[].messages[]`;
- `result.data[].publications[]`;
- `result.data[].encumbrances[].items[]`.

Обогащаются ссылки на поддерживаемые страницы сообщений на `fedresurs.ru` (включая адреса `/bankruptmessages/{id}` и `/sfactmessages/{id}`). Для записей без такой ссылки поля текста не добавляются. Существующие поля и написание `commmon` сохранены для совместимости.

### Загрузка и ошибки

Тексты загружаются онлайн со страниц сообщений через CDP. Повторяющаяся ссылка читается один раз за запрос, а текст добавляется во все соответствующие записи. Загрузка текстов не расширяет список публикаций, собранный основным парсером, и не означает выгрузку всей истории Федресурса.

Если загрузка текста не удалась, выполняется одна повторная попытка. При повторном сбое возвращается ошибка всего результата, а не успешный ответ с пропущенными текстами:

```json
{
  "status": 500,
  "data": [],
  "error": "wait retry"
}
```

Это содержимое `results.<method>.result`; служебный статус spider — `error`. Таймаут, ошибка сайта или отсутствие доступного блока текста не трактуются как отсутствие сообщения. Дополнительные переходы по сообщениям могут увеличить время выполнения запроса.
