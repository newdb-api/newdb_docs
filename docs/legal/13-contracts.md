# contracts — Государственные контракты (ЕИС Закупки 44-ФЗ / 223-ФЗ)

POST `https://api.newdb.net/v2`

Метод осуществляет поиск и сбор данных по заключенным, исполняемым и завершенным государственным и муниципальным контрактам на официальном портале **Единой информационной системы в сфере закупок** ([zakupki.gov.ru](https://zakupki.gov.ru)).

Поддерживается поиск контрактов юридических лиц по:
- **ИНН организации** (10 цифр);
- **Реестровому номеру контракта** (`reestrNumber`);
- **Прямой ссылке на карточку контракта** (`url`).

## Когда использовать

- **Анализ выручки и коммерческой активности контрагента**: объем выигранных и исполненных государственных заказов.
- **Оценка надежности поставщика**: наличие претензий, стадия исполнения, история контрактов с крупнейшими заказчиками.
- **Проверка зависимости от одного заказчика**: диверсификация портфеля госконтрактов.
- **Тендерный скоринг и комплаенс**: соответствие требованиям заказчиков по опыту выполнения аналогичных договоров.

## Входная схема

```json
{
  "method": "contracts",
  "inn": "7712345678",
  "reestrNumber": "2770123456725000041",
  "download_documents": false,
  "max_pages": 1,
  "records_per_page": "_10"
}
```

### Описание параметров

| Параметр | Тип | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `method` | string | Да | Всегда `"contracts"` |
| `inn` | string | Да* | ИНН организации (10 цифр). Обязателен при поиске по организации |
| `reestrNumber` | string | Нет* | Реестровый номер контракта в ЕИС (если требуется конкретный контракт) |
| `url` | string | Нет* | Прямая ссылка на карточку контракта в ЕИС |
| `download_documents` | boolean | Нет | Флаг загрузки приложенных документов (PDF, XML, DOCX, ZIP). По умолчанию `false` |
| `max_pages` | integer | Нет | Максимальное число страниц поисковой выдачи для обхода. По умолчанию `1` |
| `records_per_page` | string | Нет | Количество записей на страницу: `"_10"`, `"_20"`, `"_50"` |
