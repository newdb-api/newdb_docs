# taxes — Уплаченные налоги и сборы организации

POST `https://api.newdb.net/v2`

Метод возвращает официальные открытые данные ФНС о суммах налогов, сборов и страховых взносов, уплаченных организацией. Данные сгруппированы по календарному году и виду платежа.

Источник: [набор открытых данных ФНС 7707329152-paytax](https://www.nalog.gov.ru/opendata/7707329152-paytax/). ФНС публикует набор один раз в год. Релиз содержит сведения за предшествующий календарный год.

Набор не включает налоги и сборы при ввозе товаров на таможенную территорию ЕАЭС и суммы, уплаченные организацией как налоговым агентом.

**Раздел:** [Юридические лица](index.md)

## Параметры запроса

| Параметр | Тип | Обязательный | Описание |
|---|---|---:|---|
| `method` | string | Да | Всегда `taxes` |
| `inn` | string | Да | ИНН российского юридического лица, строго 10 цифр |
| `country` | string | Нет | Код страны, по умолчанию `ru` |
| `format` | string | Нет | `kontur` или `pokus` — ответ в структуре, эквивалентной `/api3/taxes` |

## Пример запроса

```bash
curl -X POST "https://api.newdb.net/v2" \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: YOUR_TOKEN" \
  -d '{
    "params": {
      "method": "taxes",
      "inn": "7840032410",
      "country": "ru"
    }
  }'
```

## Поля ответа

| Поле | Тип | Описание |
|---|---|---|
| `inn` | string | ИНН организации |
| `organization_name` | string | Полное наименование организации из набора ФНС |
| `taxes[].year` | integer | Год, за который уплачены суммы |
| `taxes[].total` | number | Сумма всех возвращенных платежей за год, рубли |
| `taxes[].data[].name` | string | Наименование налога, сбора или страхового взноса |
| `taxes[].data[].sum` | number | Уплаченная сумма в рублях |
| `source_release_date` | string | Дата выпуска файла ФНС |
| `as_of_date` | string/null | Дата состояния сведений в документе ФНС |

## Организация не найдена

Отсутствие строки в открытом наборе является завершенным результатом проверки и не считается системной ошибкой.

```json
{
  "status": 200,
  "found": false,
  "registry_status": "not_found",
  "data": []
}
```

## Совместимость с `/api3/taxes`

Передайте `format: "kontur"` в теле запроса либо `format=kontur` в query string. Ответ будет преобразован в массив объектов:

```json
[
  {
    "inn": "7840032410",
    "taxes": [
      {
        "year": 2025,
        "total": 430266.0,
        "data": [
          {"name": "Налог на прибыль организаций", "sum": 430266.0}
        ]
      }
    ]
  }
]
```

## Актуальность

Загрузочный процесс проверяет новый годовой релиз 5 апреля. История предыдущих лет сохраняется. Исправленный повторный релиз за тот же год полностью заменяет данные этого года атомарно после успешного разбора архива.
