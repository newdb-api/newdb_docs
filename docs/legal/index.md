# Юридические лица

Раздел содержит методы NEWDB для проверки юридических лиц по ИНН: арбитражные дела, блокировки счетов, признаки банкротства, исполнительные производства ФССП, бухгалтерская (финансовая) отчетность ГИР БО, сведения из ЕГРЮЛ и комплексную проверку контрагента.

## Доступные методы

- [arbitr_legal](01-arbitr_legal.md) — арбитражные дела юрлица в КАД
- [fns_block](02-fns_block.md) — блокировки счетов юрлица по данным ФНС
- [bankrot_legal](03-bankrot_legal.md) — банкротство юрлица через Федресурс
- [egrul](04-egrul.md) — сведения ЕГРЮЛ и карточка компании из Прозрачного бизнеса
- [fssp_legal](05-fssp_legal.md) — исполнительные производства ФССП по ИНН юридического лица
- [ods_case_search](06-ods_case_search.md) — поиск судебных дел по ODS с пагинацией
- [pledge_legal](07-pledge_legal.md) — залоги, лизинг и обременения юрлица по ИНН
- [complex_by_inn](06-complex_by_inn.md) — комплексная проверка компании по ИНН, включая руководителей и учредителей
- [kad_event_monitor](08-kad_event_monitor.md) — процессуальный контроль и мониторинг изменений по делу КАД
- [fns_bo](09-fns_bo.md) — бухгалтерская (финансовая) отчетность организации (ГИР БО / ФНС)
- [rnp](10-rnp.md) — Реестр недобросовестных поставщиков ЕИС Закупки (44-ФЗ, 223-ФЗ, ПП РФ 615)
- [fns_msp](11-fns_msp.md) — Реестр субъектов МСП и мер государственной поддержки
- [proverki_knm](12-proverki_knm.md) — Единый реестр проверок (ФГИС ЕРП / ЕРКНМ) Генеральной прокуратуры РФ
