# proverki_knm — Единый реестр проверок (ФГИС ЕРП / ЕРКНМ)

POST `https://api.newdb.net/v2`

Метод осуществляет поиск сведений в официальной системе **ФГИС «Единый реестр контрольных (надзорных) мероприятий» / «Единый реестр проверок»** Генеральной прокуратуры РФ ([proverki.gov.ru/portal/public-search](https://proverki.gov.ru/portal/public-search)).

Поддерживается поиск по **ИНН юридического лица (10 цифр)**, **ИНН индивидуального предпринимателя (12 цифр)** или общему поисковому запросу.

Метод проверяет проверки по:
- **248-ФЗ** (Федеральный закон «О государственном контроле (надзоре) и муниципальном контроле в РФ»);
- **294-ФЗ** (Федеральный закон «О защите прав юридических лиц и индивидуальных предпринимателей при осуществлении государственного контроля (надзора) и муниципального контроля»).

---

**Раздел:** [Юридические лица](index.md)

> [!IMPORTANT]
> Метод предназначен для анализа регуляторных рисков компаний и ИП: плановых и внеплановых проверок МЧС, Роспотребнадзора, Роструда, Ростехнадзора, Росприроднадзора, налоговых и прокурорских органов.
> 
> Автоматически решает графические капчи провайдера, агрегирует постраничную пагинацию и возвращает структурированный список мероприятий со ссылками на карточки проверок.

## Когда использовать

- **Проверка контрагентов перед сделками**: выявление предстоящих выездных и документарных проверок надзорных органов.
- **Мониторинг собственного бизнеса**: своевременное обнаружение включения организации в ежегодный сводный план проверок прокуратуры.
- **Оценка административной нагрузки и рисков**: ретроспектива и статистика проведенных проверок, предписаний и выявленных нарушений.

## Входная схема

```json
{
  "params": {
    "inn": "string, optional, ИНН организации (10 цифр) или ИП (12 цифр)",
    "query": "string, optional, Поисковый запрос / номер КНМ / наименование",
    "max_pages": "integer, optional, Максимальное число страниц для скачивания (1-20, по умолчанию 5, 50 записей на страницу)",
    "country": "ru",
    "method": "proverki_knm"
  },
  "webhook": "https://your.host/webhook",
  "requestId": "optional-string"
}
```

> [!NOTE]
> В параметрах допустимо указывать `method: "proverki_knm"` или `method: "proverki_gov"` (псевдонимы).
> Обязательно указание `inn` или `query`.

---

## Параметры запроса

| Параметр | Тип | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `inn` | string | Да* | ИНН проверяемого лица (10 цифр для юрлиц, 12 для ИП). Допускаются алиасы `innfiz`, `innyur`, `searchString`. |
| `query` | string | Да* | Произвольная поисковая строка (если `inn` не указан). |
| `max_pages` | integer | Нет | Лимит загружаемых страниц результатов (от 1 до 20, по умолчанию 5). На каждой странице до 50 записей. |
| `timeout_ms` | integer | Нет | Таймаут ожидания загрузки страницы и решения капчи (по умолчанию 45000 мс). |
| `country` | string | Нет | Код страны, по умолчанию `"ru"`. |
| `method` | string | Да | Имя метода: `"proverki_knm"` или `"proverki_gov"`. |

*\* Требуется передать хотя бы `inn` или `query`.*

## Описание полей ответа

| Поле в `data[]` | Тип | Описание |
| :--- | :--- | :--- |
| `id` | string | Уникальный системный идентификатор мероприятия в ФГИС ЕРП / ЕРКНМ. |
| `number` | string | Учетный номер КНМ (контрольного надзорного мероприятия). |
| `federal_law` | string | Федеральный закон, в рамках которого проводится проверка (`"248"`, `"294"`). |
| `inn` | string | ИНН проверяемого лица. |
| `ogrn` | string | ОГРН проверяемого лица. |
| `company_name` | string | Наименование юридического лица или ФИО индивидуального предпринимателя. |
| `month_start` | string | Плановый месяц и год начала проведения проверки (например, `"Ноябрь 2026 года."`). |
| `control_org_name` | string | Полное наименование контрольного (надзорного) органа. |
| `prosecutor_org_name` | string | Наименование органа прокуратуры, согласующего проверку. |
| `details_url` | string | Прямая ссылка на карточку мероприятия на портале `proverki.gov.ru`. |
| `knm_type` | string | Тип мероприятия (например, `"Плановое КНМ"` или `"Внеплановое КНМ"`). |
| `term` | string | Срок проведения мероприятия (например, `"10 дней 80.0 часов"`). |
| `address` | string | Адрес места нахождения объекта контроля. |
| `carryout_name` | string | Форма проведения проверки (например, `"Выездная проверка"`, `"Документарная проверка"`). |
| `decision` | boolean | Признак наличия решения по результатам КНМ. |
| `raw` | object | Исходный структурированный объект ответа провайдера. |
